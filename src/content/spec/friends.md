## 怎么申请友链？

想要交换友链的小伙伴们，欢迎去本站的 [Github 仓库](https://github.com/sixtdreanight/Blog-mizuki)提交一个 PR。审核通过后，就可以在这里展示啦。

请编辑 `src/data/friends.ts`，在 `friendsData` 数组中添加你的信息，参考格式：

```ts
{
    id: <序号>,
    title: "网站名称",
    imgurl: "头像地址",
    desc: "一句话介绍下你的网站或者你自己",
    siteurl: "网站地址",
    tags: ['Blog', 'Tech'],
},
```
